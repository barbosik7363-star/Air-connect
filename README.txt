PairDemo - iPhone, готовая структура для GitHub

1. Создайте репозиторий на GitHub и загрузите все файлы из этой папки
   (сохраняя структуру: project.yml, PairDemo/, .github/workflows/).
2. Перейдите во вкладку Actions и запустите "Build IPA" (Run workflow)
   либо дождитесь автозапуска после push.
3. Когда сборка завершится, скачайте артефакт PairDemo-ipa.

Важно: этот IPA не подписан. Установить его на iPhone напрямую нельзя.
Для установки нужен Apple Developer аккаунт, сертификат и provisioning profile;
их добавляют в workflow отдельным шагом подписи (это можно сделать следующим шагом).
Код не проверен на устройстве: если сборка упадёт, пришлите лог ошибки из Actions.
